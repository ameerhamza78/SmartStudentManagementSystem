Smart Student Management System
Project Overview

This project is a Containerized Full-Stack Student Management System developed using:

ASP.NET Core MVC
C#
SQL Server
Entity Framework Core
REST API
Docker & Docker Compose

The system allows administrators to manage student records through complete CRUD operations.

Features
Add Students
Edit Students
Delete Students
View Student Records
SQL Server Integration
REST API Support
Docker Containerization
Multi-container Deployment
Technologies Used
Technology	Purpose
ASP.NET Core MVC	Web Development
C#	Backend Logic
SQL Server	Database
Entity Framework Core	ORM
Docker	Containerization
Docker Compose	Multi-container Setup
Docker Setup

Run the following command:

docker-compose up --build
